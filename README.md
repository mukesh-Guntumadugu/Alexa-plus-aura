# Bee Wearable AI Enhancements

## Overview
This is a repository for exploring and building enhancements for the **Bee (Wearable AI)** ecosystem.

## Requirements
- Build a project that connects to real data recorded and processed through a Bee device or an Apple Watch running Bee software.
- Use Bee's CLI, MCP, or Agent Skills.
- The demo must show the project actually using live Bee data to do something useful for a person.
- Priority use cases: education, developer experience, and personal productivity.
