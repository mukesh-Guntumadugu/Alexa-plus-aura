# Bee Wearable AI Enhancements

## Overview
This is a repository for exploring and building enhancements for the **Bee (Wearable AI)** ecosystem.

## Requirements
- Build a project that connects to real data recorded and processed through a Bee device or an Apple Watch running Bee software.
- Use Bee's CLI, MCP, or Agent Skills.
- The demo must show the project actually using live Bee data to do something useful for a person.
- Priority use cases: education, developer experience, and personal productivity.

## Existing Bee Features (What not to build)
Bee already has several powerful core features. We want to build something that extends beyond these:
- Conversation transcription (speech into text).
- Summaries & takeaways of discussions.
- Automatic to-dos (detects intent like “I need to email John tomorrow”).
- Reminders of things that came up during conversations.
- Personal memory (remembers people, relationships, topics, preferences, past work).
- Q&A about your past (e.g., “What did I discuss with John yesterday?”).
- Daily memories / daily brief (organizes your day).
- Patterns and insights (identifies trends in behavior/routines over time).
- Voice notes (hold the button and speak a note directly).
- Conversation bookmarking (double-press to mark/process a conversation).
- Search your history (keyword and semantic/AI search).
- Integrations/actions (connects memory to calendar/email and other AI tools).
